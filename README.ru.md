# MixBar

Небольшой микшер громкости приложений для строки меню macOS.

Spotify орёт, а созвон еле слышно? В MixBar у каждого приложения свой ползунок
и кнопка mute. Внутри — Core Audio process taps: без виртуального
аудиодрайвера, без kext и без прав администратора.

**Статус:** ранняя версия, но уже работает. Собрано и проверено на Apple
Silicon.

## Установка

Скачайте последнюю **DMG** из
[Releases](https://github.com/hikara192/MixBar/releases/latest), откройте её,
перетащите MixBar в «Программы» и запустите. Терминал не нужен.

Приложение пока не notarized (для этого нужна платная учётная запись Apple
Developer), поэтому macOS может заблокировать первый запуск. Разрешите один
раз:

- правый клик по MixBar в «Программах» → **«Открыть»**, или
- «Настройки системы» → «Конфиденциальность и безопасность» → **«Всё равно
  открыть»**.

Потом включите музыку и разрешите **System Audio Recording** (запись
системного звука).

### Сборка из исходников

Если хотите собрать сами или что-то поменять:

**Нужно:** macOS 14.2 или новее и Xcode Command Line Tools. Если `swift` не
найден, сначала выполните `xcode-select --install`.

```bash
git clone https://github.com/hikara192/MixBar.git
cd MixBar
./Scripts/build-app.sh release
cp -R build/MixBar.app /Applications/
open /Applications/MixBar.app
```

Хотите ZIP? [Скачайте исходники](https://github.com/hikara192/MixBar/archive/refs/heads/main.zip),
распакуйте и выполните те же команды в папке.

Локальная сборка тоже подписана ad-hoc, поэтому macOS считает каждую
пересборку новым приложением — после неё, возможно, придётся заново разрешить
захват звука.

### Первый запуск

1. Включите музыку или видео в любом приложении.
2. Нажмите на иконку ползунков в строке меню.
3. Сдвиньте ползунок. macOS спросит разрешение на **System Audio Recording**
   (запись системного звука) — разрешите.
4. Готово. Ползунок меняет громкость приложения, а индикатор показывает его
   реальный уровень.

Если ползунок двигается, а звук не меняется: откройте «Настройки системы» →
«Конфиденциальность и безопасность» → **«Запись экрана и системного звука»**,
включите MixBar и нажмите **«Повторить»** в панели MixBar.

## Как пользоваться

В панели видны только приложения, которые сейчас издают звук. Поставили музыку
на паузу — приложение пропало; включили снова — вернулось.

- **Ползунок** — громкость приложения от 0 до 100%.
- **Кнопка динамика** — mute для этого приложения.
- **100%** — MixBar полностью убирает свой захват. Приложение снова играет без
  изменений (bit-perfect) и без накладных расходов.
- **Шестерёнка** — настройки.

MixBar живёт только в строке меню. Иконки в Dock и главного окна нет.

## Настройки и горячие клавиши

Настройки открываются шестерёнкой в панели или по ⌘, когда MixBar активен.

- **Основные** — язык интерфейса (Системный / English / Русский, применяется
  сразу) и запуск при входе.
- **Звук** — текущий статус захвата, устройство вывода, переход в настройки
  системы, «Повторить» и сброс всех громкостей до 100%.
- **Сочетания** — глобальные горячие клавиши: рекордер и включение/выключение
  для каждого действия.
- **О программе** — версия и режим движка.

По умолчанию:

- **⌥⌘M** — выключить или включить звук всех приложений.
- **⌥⌘R** — сбросить все громкости до 100%.

Работают, даже когда MixBar неактивен. Разрешения Accessibility и Input
Monitoring не нужны.

## Что стоит знать

- Одновременно можно управлять максимум 16 приложениями.
- Приложения, которые сейчас не играют звук, в список не попадают — так
  задумано.
- Усиления выше 100%, эквалайзера и отдельного вывода для каждого приложения
  пока нет.
- Несколько профессиональных аудиохостов (Logic, Ableton, Pro Tools, …)
  исключены намеренно, чтобы MixBar не воевал с ними за аудиоустройство.
- Если строка меню переполнена, macOS может спрятать иконку. Зажмите ⌘ и
  перетащите её в видимое место.

## Как это работает

Для каждого приложения, которое вы трогаете, MixBar создаёт Core Audio process
tap, отправляет все захваты в одно приватное агрегатное устройство и микширует
их в одном real-time колбэке. Приложения на 100% не захватываются и играют
своим обычным путём.

Полное описание архитектуры, решений и компромиссов — в
[ARCHITECTURE.md](ARCHITECTURE.md).

## Разработка

```bash
swift build
swift test                 # 45 тестов: рендер, reconciler, настройки, локализация, горячие клавиши
Scripts/check-deps.sh      # проверки зависимостей и чистоты real-time пути

Scripts/build-app.sh       # собирает build/MixBar.app
Scripts/make-dmg.sh        # собирает build/MixBar-<версия>.dmg для Releases
Scripts/make-icon.sh       # пересоздаёт иконку приложения
```

Запуск интерфейса без Core Audio (синтетический звук, разрешение не нужно):

```bash
MIXBAR_ENGINE=fake open build/MixBar.app
```

## Приватность

MixBar не записывает звук и никуда его не отправляет. Захваченные потоки
микшируются в памяти и сразу идут на устройство вывода.
